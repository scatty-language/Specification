# Scatty Language Specification

[![License](https://img.shields.io/badge/License-Apache_2.0_with_LLVM_Exception-blue.svg)](LICENSE)
[![Encoding](https://img.shields.io/badge/Encoding-UTF--8-lightgrey.svg)](#)

This repository contains the formal technical specification for the Scatty programming language. It defines the formal grammar, lexical structure, type system, runtime semantics, and binary interface conventions.

The specification serves as the primary reference for compiler authors, runtime developers, and tooling implementers.

## Status and Contributions

This specification is an active, evolving reference. Details are subject to revision as implementation feedback and language proposals progress.

To propose revisions, report ambiguities, or correct errata, submit an issue or pull request with a rationale and cross-references to the affected sections.
