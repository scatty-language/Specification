This repository contains the technical specification and long-term architectural vision for the Scatty programming language. It outlines the intended formal grammar, lexical structure, type system, runtime semantics, and binary interface conventions.

## Status and Scope

There is currently no compiler, runtime, or tooling implementation for Scatty.

At this stage, this repository serves a dual purpose: formal technical specification and comprehensive vision document.

Because the specification aims to capture the complete architecture of the language upfront, it includes a wide range of features. Not all of them are intended for an initial release.

Once development of the compiler and runtime begins, this document will serve as the primary blueprint for implementers. Details remain subject to revision as theoretical design meets practical implementation constraints.

## Contributions

This specification is an active, evolving reference. Design reviews, edge-case analyses, and technical feedback are welcome.

To propose revisions, report ambiguities, or correct errata, submit an issue or pull request with a clear rationale and cross-references to the affected sections.
